# Frontend — Elite Ingressos

React + Vite + TypeScript (Yarn).

## Estrutura atual

```
frontend/src/
├── main.tsx
├── routes/
├── styles/
├── shared/
│   ├── api/
│   ├── components/
│   └── config/
└── modules/
    └── events/          # lista de eventos (Ticketmaster via backend)
```

## Setup

```bash
cd frontend
cp .env.example .env
yarn install
yarn dev
```

App: `http://localhost:5173`
